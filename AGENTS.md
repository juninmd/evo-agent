# AGENTS.md

`evo-agent`: TypeScript self-improving AI publishing agent with a Tauri 2 desktop console (`desktop/`).

Core flow: crawl AI/developer sources into SQLite -> improve agent state -> generate pt-BR articles and weekly reports -> publish Markdown and Jekyll assets to GitHub Pages -> notify Telegram after a successful publish.

## Persona and priorities

- Super Expert, hierarchy SecOps > QA > DevOps > SWE. Prefer evidence, small diffs and reproducible checks. Keep prose compressed and technical.
- Protect secrets. Never print tokens, credentials or private env values.

## Stack

- Agent: TypeScript (Node), SQLite, Vitest, Biome (`biome.json`)
- Desktop: Tauri 2, React 19, Tailwind v4, Rust (`desktop/src-tauri/`), own `package.json`

## Commands

```bash
npm ci                       # never --legacy-peer-deps: it drops the zod peer and dist/, then fails with ERR_MODULE_NOT_FOUND
npm run lint
npm run build
npm test
npm run test:coverage
npm run benchmark:editorial
npm run smoke:reddit-comments   # isolated DB, before enabling the Reddit flow in production

# desktop/ has its own package and gate
cd desktop && npm run lint && npm test && npm run build && npm run e2e
cd desktop/src-tauri && cargo fmt --check && cargo clippy --all-targets --locked -- -D warnings && cargo test --locked
```

## Structure

- `src/config.ts`, `src/index.ts` — config and entry point
- `src/api/` — `RUN_MODE=API` HTTP server for the desktop console (`routes.ts`, `runs.ts`, `auth.ts`)
- `src/crawler/` — source crawlers (Reddit smoke script included)
- `src/knowledge/store.ts` — SQLite store; `src/agent/` — improver and writer
- `src/publisher/` — GitHub Pages builder (`github.ts`, `site-renderer.ts`, `styles/`)
- `src/notifier/telegram.ts`; `src/utils/`
- `src/__tests__/` — includes `docs-drift.test.ts`
- `desktop/src/lib/api.ts` — the only place that calls `invoke()`; IPC types live here
- `desktop/src-tauri/src/` — `client.rs`, `commands.rs`, `cmd_feeds.rs`, `cmd_runs.rs`, `settings.rs`, `types.rs`
- `docs/prints/` — screenshots regenerated by e2e

## Development rules

- Read before write. Keep changes surgical; do not refactor adjacent code unless required.
- Run `npm run build` and `npm run lint` before calling work done.
- Never commit generated SQLite databases, WAL/SHM files, local reports or secrets.

## Publishing rules (GitHub Pages)

- The Pages UI must keep: light/dark theme toggle (`aria-pressed`), archive by year/month, dark- and light-readable article content, Markdown download button, corrected header anchors for `Arquivo` and `Relatorios`, canonical URL, Open Graph/Twitter metadata, Atom feed and sitemap, skip link, "Nesta edição" table of contents, and the primary-source / community-signal markers.
- Both layouts come from the shared builders in `site-renderer.ts`; do not fork them. CSS lives in `src/publisher/styles/`; bump the `site.css?v=` query when it changes.
- Every `{{ page.* }}` interpolation must carry `| escape`. Liquid does not escape by default, and titles come from crawled text.
- Articles may include images or videos when they improve validation or reader understanding.

## Security rules

- Keep `.env` local. `API_TOKEN` must never cross IPC: `settings_get` answers `hasToken`, never the value.
- Rotate any token that returns `401 Bad credentials`.
- Pages publishing uses a GitHub app/connector or a valid token.
- Community comments are signals, not authoritative sources.

## Console rules

- Every `/api/v1` payload is camelCase, including SQL aliases. `desktop/src-tauri/src/types.rs` mirrors the keys field by field; a `snake_case` key is a runtime break, not a compile error.
- A Rust command name must equal its `invoke` name in `desktop/src/lib/api.ts`. `desktop/src/lib/api.test.ts` pins both sides.
- The API is read-only. `POST /api/v1/runs` spawns a child process instead of running the cycle in the API process, and only when `API_ALLOW_RUNS=true` (default false).
- After changing the API contract, run `cargo test --test live_api -- --ignored` against a live agent (`desktop/src-tauri/tests/live_api.rs`). It is the only test that compares the structs with the JSON Node returns.
- A UI change goes through `npm run e2e` and ships regenerated screenshots in `docs/prints/` in the same PR.
- Tab labels and labels derived from API enums are pt-BR. Raw contract values are translated at the edge in `desktop/src/lib/i18n.ts`, never printed as they arrive.

## CI gates

`.github/workflows/ci.yml` runs on PRs and pushes to `main`:

- `test`: lint, build, `npm test`, `benchmark:editorial`, `test:coverage`, `npm audit --omit=dev --audit-level=moderate`.
- `desktop`: lint, test, build, `npm run e2e`; `npm audit` is non-blocking.
- `desktop-rust`: `cargo fmt --check`, clippy with `-D warnings`, `cargo test --locked`.
- `gitleaks`: full-history secret scan.
- `docker.yml` and `security.yml` call `juninmd/base-actions` reusable workflows.
- `src/__tests__/docs-drift.test.ts` fails if README.md lacks an env var read by `src/` or a `RUN_MODE` row.
