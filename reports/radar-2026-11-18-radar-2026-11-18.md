## TL;DR
1. Google lançou Gemini 4 Neon com 1.048.576 tokens de contexto, modelo mid-tier da família Gemini 4 otimizado para coding e trabalho agente.
2. Cloudflare tornou Clairic e Clairic-flash open-weight via Workers AI Superintelligence team, graduando Clairic de preview.
3. Microsoft lançou Foundry Dev Pack em GA no Ignite 2026, kit para construir agentes Foundry no editor, terminal ou coding agent preferido.
4. Microsoft anunciou Browser Automation Tool no Foundry com MCP action batching, Live View, session recording, VNet injection e CAPTCHA handling.
5. Microsoft Foundry Agent Service recebeu hosted agents em produção com shared subnet IPs, private CA trust, network egress controls e deployment em AKS próprio.
6. OpenCode v2.3.2 corrigiu GPT-6.2 prompt caching enviando system prompt como leading developer message no Responses API para evitar re-billing.
7. OpenCode v2.3.1 fez timed-out shell commands continuarem em background em vez de serem killed, com foreground timeout 0 para manter foreground.
8. OpenAI Agents SDK v0.25.0 expôs utilities para third-party session adapters, removeu Runloop provider do sandbox e adicionou opt-in handoff error recovery.
9. Dify v1.20.0 adicionou export de traces para qualquer OpenTelemetry collector, compatibilidade pós-retirement do endpoint legacy Langfuse e malware scan em knowledge files.
10. VS Code 1.148 Insiders trouxe agent session management e melhorias em editor tabs, além de migração do Local harness para Copilot harness.
11. MiniMax-H3-Image trending no HF (sinal 816) com 1.457 likes e 727.110 downloads como modelo text-to-image.
12. Qwen/Qwen3.8-27B trending no HF (sinal 507) com 20.426 likes e 6,9M downloads como modelo image-text-to-text.

## O que observar
- Gemini 4 Neon entra no top 10 do Índice de Inteligência da Artificial Analysis, competindo diretamente em coding/agentic com Claude e GPT-6.x.
