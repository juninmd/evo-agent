### Claude Code: Uso de múltiplos agentes

**Novidade:**  
Para projetos 2026, a recomendação é utilizar *multiple agents* em vez de um único agente, permitindo dividir responsabilidades e otimizar o desempenho do código assistido.

**Como usar:**  
1. Defina cada agente com uma tarefa específica (ex.: compilador, teste, documentação).  
2. Configure o agente mestre para delegar subtarefas aos agentes auxiliares usando a API de *delegation*.  
3. Mantenha um *context manager* centralizado para compartilhar dados entre agentes em tempo real.

**Boa prática:**  
Use múltiplos agentes quando o projeto crescer em complexidade e evitar a sobrecarga de um único fluxo de trabalho. Evite criar agentes demais que complica a depuração e o controle de estado.

**Exemplo:**  
```bash
agent_mestre create
agent_child compile
agent_child test
agent_child docs
agent_mestre delegate compile
```

### OpenCode: Formatos JSON e Markdown em relatórios e resultado de imagens

**Novidade:**  
Versão v1.18.35 adiciona suporte a *canonical redirects* e permite que os agentes retornem dados em formatos JSON e Markdown, além de incluir imagens suportadas pelo xAI nos resultados de ferramentas.

**Como usar:**  
1. No arquivo de configuração do agente, defina `output_format: json` ou `output_format: markdown`.  
2. Ao chamar uma ferramenta que gera imagens, certifique-se de que o resultado seja produzido em formato suportado pelo xAI (png, jpg).  
3. Utilize o parâmetro `include_images: true` para incluir imagens nos logs.

**Boa prática:**  
Adote esses formatos quando precisar exportar relatórios legíveis por humanos ou para integração com dashboards. Evite misturar JSON e Markdown na mesma resposta; escolha conforme o consumidor final.

**Exemplo:**  
```yaml
agent:
  name: BuildReporter
  output_format: markdown
  include_images: true
```
